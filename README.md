E-commerce desenvolvido como Trabalho de Conclusão de Curso de Engenharia de Software, com o objetivo de oferecer uma plataforma para compra e gerenciamento de produtos online.

## Funcionalidades

- Catálogo e visualização de produtos.
- Carrinho de compras.
- Cadastro e autenticação de usuários.
- Gerenciamento de perfil e endereços.
- Realização e acompanhamento de pedidos.
- Painel administrativo para gerenciamento de usuários e pedidos.

## Tecnologias

**Back-end:** PHP, Laravel e MySQL.

**Front-end:** Vue.js, JavaScript, HTML5 e CSS3.

**Infraestrutura e ferramentas:** Docker, Git e GitHub.
